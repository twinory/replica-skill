! Husk filter list. Adblock Plus syntax subset.
! Parsed by lib/core/blocklist.dart. Keep it to what that parser understands:
!   ||domain^            block any URL on that domain
!   ||domain/path^       block that path
!   |https://exact|      block one exact URL
!   /regex/              block by regular expression
!   @@...                exception, wins over every block above
!   ##selector           hide an element on every site
!   site.com##selector   hide an element on that site
!   site.com#@#selector  do not hide that element on that site
!
! Rules go to WKContentRuleList on iOS and to the WebView content blocker on
! Android. Anything blocked here never reaches the page, so it cannot be
! counted pixel by pixel. There are no counters faked in the UI.
